# Games

- [Build Your Village](build-your-village/) — a cozy low-poly village builder that runs in the browser. Open `build-your-village/index.html` to play.
- [BEYOND – The Lost World](beyond-lost-world/) — a 3D first-person exploration adventure (Three.js). Run `npm start` in `beyond-lost-world/` and open http://localhost:5173.
