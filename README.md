# Games

- [Build Your Village](build-your-village/) — a cozy low-poly village builder that runs in the browser. Open `build-your-village/index.html` to play.
- [Claw Machine Simulator](claw-machine-simulator/) — a 3D Roblox-style simulator: grab plush animals from your own claw machine, collect and equip them as pets, train, upgrade and unlock new arcades. Open `claw-machine-simulator/index.html` to play.
