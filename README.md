# Games

- [Build Your Village](build-your-village/) — a cozy low-poly village builder that runs in the browser. Open `build-your-village/index.html` to play.
- [Mini Supermarket](mini-supermarket/) — a colourful supermarket tycoon in the browser (Dutch UI): serve customers, manage stock, hire staff and grow one shop into a chain of five. Open `mini-supermarket/index.html` to play.
